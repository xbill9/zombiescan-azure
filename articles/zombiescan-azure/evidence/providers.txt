A provider that is not registered on a subscription is skipped, not reported as an error: a 
subscription that never used a service has no waste in it. zombiescan checks registration first 
because ARM answers an unregistered provider's list call with an empty page rather than an error, 
which would otherwise read as a clean subscription.
